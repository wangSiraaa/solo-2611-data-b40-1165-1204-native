# 叠色接印样例

单行 `1×3` 纸面，两块实际版面各对应一个目录版本（同一 `tile_id` 的不同 `revision`：

- `PLATE@1` = `[2,1,0]`（第一版，蓝）
- `PLATE@2` = `[0,2,0]`（第二版，黄）
- `PLATE@3` = `[2,1,0]`（把第二版改成与第一版同高，用于“改版盖蓝”）
- `PLATE@4` = `[0,1,0]`、`PLATE@5` = `[1,0,1]`（完整纸边的夹条样例）

压力脚下落规则：整版为一只四邻相连的压力脚，`深度 0` 时只有脚下最高格沾墨。

## 四笔订单

| 订单 | 版号（蓝/黄） | 过程 | 位移 | 结果 |
| --- | --- | --- | --- | --- |
| `TWO-COLOR` | 1 / 2 | 定位孔 | (0,0) | **可印**：纸上 `蓝,黄,白`，无串色 |
| `CHANGED-PLATE` | 1 / 3 | 定位孔 | (0,0) | **拒**：`(0,0)` 串色（黄盖蓝），缺蓝 |
| `REJECT-MIDDLE-YELLOW` | 1 / 2 | 定位孔 | (0,0) | **拒**：成品纸中格拒收黄墨，缺黄 |
| `CLAMP-FULL-EDGE` | 4 / 5 | 夹条 | 由可见点定为 (0,1) | **可印**：`白,黄,蓝`，纸边完整 |

### 说明

1. **两色可印。** 蓝 `[2,1,0]` 深度 0 → 只在格 0 沾蓝；黄 `[0,2,0]` → 只在格 1 沾黄。
   原位 (0,0) 落纸得 `蓝,黄,白`，蓝黄不重叠。用定位孔：两遍都按同一组孔走，位移相同、
   配准稳定。
2. **只改第二版成 `[2,1,0]` 便盖掉蓝。** 黄的最高格移到格 0，与蓝同位；两墨重叠，油墨
   表里黄在后（`ink_overlay=["blue","yellow"]`）→ 格 0 显黄，蓝被盖。缺蓝且格 0 是串色格。
3. **还原第二版、只让成品纸中格拒收黄墨。** 黄本应落在格 1，但唯一可交付的成品纸
   `paper_rejects` 拒收 `(0,1)` 的黄 → 缺黄，仍不可接。
4. **夹条新单（完整纸边）。** 订单要完整纸边，定位孔会打掉图边，故强制走夹条过程。
   第一遍留下的两处对位点在 `(0,1)`、`(0,2)` 纸张格，夹条遮住 `(0,2)`，馆方只见 `(0,1)`
   那一点。候选位移 `{(0,0),(0,1)}` 中只有 `(0,1)` 能重放这唯一所见 → 唯一承诺。
   在 `(0,1)` 下蓝 `[0,1,0]` 与黄 `[1,0,1]` 落纸得 `白,黄,蓝`，无串色，纸边完整。

## 运行

```bash
python3 -m slabwater overprint materials/overprint/input.json --db-dir /tmp/op
python3 -m slabwater reopen-print /tmp/op <print_id>
```

`reopen-print` 从已存实印单取回两层版号、纸上逐格颜色与碰到的源块
（如 `PLATE@1`、`PLATE@2`），并重算核验，不依赖事后目录版本。
